# Feature Specification: Tetris Slide Game (10x10) — 完全リビルド

**Feature Branch**: `001-tetris-slide-game`
**Created**: 2026-05-08
**Status**: Draft
**Input**: User description: "今あるcodeと完全に変えたい、2048 gameのベースに数字ではなく、テトリスのブロックをswipeするとブロックが移動され、ブロックが一行になると消えるのゲームにしたい、そしてboardも10x10にしたい、実際ゲームできるように考えて、わからないことは質問攻めで聞いて"

## Overview

既存の 2048 系アプリ（NumberClash / Reverse2048）を完全に置き換え、新しいゲームに作り
直す。新ゲームは 10×10 の盤面上で、テトリスのピース（I / O / T / S / Z / J / L）を
2048 のように上下左右にスワイプして滑らせ、満杯になった横一行が消えるパズルゲームで
ある。シングルプレイのエンドレスモードとし、ハイスコアの記録・更新を中心とする
体験を提供する。

## User Scenarios & Testing *(mandatory)*

### User Story 1 — コアゲームプレイ (Priority: P1)

プレイヤーは 10×10 の盤面でテトリスのピースを 2048 風にスワイプし、横一行を
揃えて消し、ピースが置けなくなるまでハイスコアを目指して遊ぶことができる。

**Why this priority**: これがなければ製品自体が存在しない。MVP の中核。

**Independent Test**: アプリを起動 → PLAY ボタンをタップ → 数十回スワイプ
→ 盤面が滑り、行が消え、スコアが増え、最後にゲームオーバー画面が出るまでを
1 セッションとして遊び切れるかを実機で確認することで完全に検証可能。

**Acceptance Scenarios**:

1. **Given** アプリ起動直後のメイン画面、**When** プレイヤーが PLAY ボタンを
   タップする、**Then** 空の 10×10 盤面が表示され、最初のピース（4 セル）が
   ランダムな空きマスにランダム回転で配置され、画面右上に NEXT として次の
   ピースの形が表示される。
2. **Given** 盤面に複数のピースのセルが置かれている状態、**When** プレイヤーが
   いずれか 1 方向（上 / 下 / 左 / 右）にスワイプする、**Then** 盤面上のすべ
   ての埋まったセルが、その方向の端または別のセルに当たるまで滑り、各セル間に
   隙間が無くなる（2048 と同じ挙動だが「合体」は起きない）。
3. **Given** スワイプ直後の盤面、**When** ある横 1 行（10 セル）がすべて埋まって
   いる、**Then** その行のすべてのセルが消え、スコアが該当ルール（1 行=100 /
   2 行=300 / 3 行=500 / 4 行=800）に従って加算される。残ったセルは消えた行
   の影響でずれることはなく、現在の位置を保つ。
4. **Given** 1 行以上の同時消去が発生したスワイプ後、**When** 行消去とスコア
   加算が完了する、**Then** 次のピースが盤面の空きマスにランダム回転で配置
   され、ピース設置ボーナス（+1）がスコアに加算され、新しい NEXT ピースが
   抽選・表示される。
5. **Given** スワイプ＋行消去＋ピース設置を試みた直後、**When** 次のピースが
   どの回転・どの位置でも盤面の空き 4 セルに収まらない、**Then** ゲームオー
   バー画面が表示され、最終スコアと（更新された場合は）NEW HIGH SCORE 表示が
   出る。
6. **Given** ゲームオーバー画面、**When** プレイヤーが PLAY AGAIN をタップ、
   **Then** 盤面が初期状態にリセットされ、新しいゲームが開始される。

### User Story 2 — ハイスコアの永続化 (Priority: P2)

プレイヤーが達成した最高スコアは端末に永続的に保存され、起動のたびに表示
される。新記録達成時は明確に祝う。

**Why this priority**: コアゲームプレイ（P1）が成立した後、リプレイ意欲を
支える要素。アプリを閉じても消えないことが前提だが、保存機構が無くても
ゲーム自体は遊べるため独立した増分。

**Independent Test**: ゲームをプレイして任意のスコアを残す → アプリを完全に
終了して再起動 → メイン画面で前回のハイスコアが表示されていること、新規
プレイで前回より高いスコアを取ると NEW HIGH SCORE 表示が出ることを確認。

**Acceptance Scenarios**:

1. **Given** 初回起動の状態、**When** メイン画面が表示される、**Then** ハイ
   スコアは 0 と表示される。
2. **Given** 過去にハイスコア 500 を記録済みの端末、**When** アプリを再起動
   する、**Then** メイン画面のハイスコア欄に 500 が表示される。
3. **Given** 現在のハイスコアが 500 の状態、**When** 新しいゲームで 800 を
   獲得して終了する、**Then** ゲームオーバー画面に NEW HIGH SCORE バッジ
   が表示され、メイン画面に戻ったときハイスコアが 800 に更新されている。

### User Story 3 — 効果音とハプティクスフィードバック (Priority: P3)

スワイプ・行消去・ゲームオーバーといった重要なイベントで、効果音と微妙な
振動が再生され、操作の手応えと爽快感を高める。

**Why this priority**: ゲームの感触を大きく左右するが、無音 / 振動なしでも
プレイ自体は完結する。後から積み増せる増分。

**Independent Test**: 設定画面で音とハプティクスを ON にして 1 ゲーム遊び、
4 行同時消し（テトリス）を 1 回起こして専用効果音と強めの振動が鳴ること、
ゲームオーバー時に専用効果音と振動が鳴ることを確認。OFF にした状態で同じ
操作をして無音・無振動になることを確認。

**Acceptance Scenarios**:

1. **Given** 音設定が ON、**When** プレイヤーがスワイプする、**Then** スワ
   イプ効果音が再生される。
2. **Given** 音設定が ON、**When** 1〜3 行が同時に消える、**Then** 通常の
   行消去効果音が再生される。
3. **Given** 音設定が ON、**When** 4 行が同時に消える、**Then** 専用の「テ
   トリス」効果音が再生される（通常行消去音より明確に異なる）。
4. **Given** ハプティクス設定が ON、**When** スワイプ成功 / 行消去 / ゲーム
   オーバーのいずれかが発生、**Then** それぞれ強度の異なる振動が短く再生
   される。
5. **Given** いずれかの設定が OFF、**When** 該当するイベントが発生する、
   **Then** その種類の効果音または振動は再生されない。

### User Story 4 — 多言語対応 (Priority: P3)

メニュー / スコア表示 / ゲームオーバー / 設定画面など、すべてのユーザー向け
文言が英語・日本語・簡体字中国語・繁体字中国語・香港中文の 5 言語で表示
される。

**Why this priority**: 既存ユーザー層の維持に必須だが、英語のみでも遊べる
ため独立した増分として追加できる。

**Independent Test**: iOS の設定で言語を順に切り替え、アプリを起動するたび
にすべての画面文字列がその言語で表示され、レイアウト崩れが起きないことを
確認。

**Acceptance Scenarios**:

1. **Given** 端末言語が日本語、**When** アプリを起動、**Then** メイン画面・
   ゲーム画面・ゲームオーバー画面・設定画面のすべての文字列が日本語で表示
   される。
2. **Given** 端末言語が簡体字 / 繁体字 / 香港中文 / 英語、**When** アプリを
   起動、**Then** 各言語の文言で UI が表示される。
3. **Given** 任意のリリース、**When** 開発者が新しい UI 文言を追加した PR を
   作る、**Then** 5 ロケールすべてで対応する翻訳が存在する（憲法 III に
   準拠）。

### User Story 5 — バナー広告 (Priority: P3)

ゲーム画面の最下部にバナー広告が常時表示される。広告はゲーム操作（スワ
イプ・タップ）を一切妨げない。EU 圏のユーザーには UMP 同意フローが、
すべてのユーザーには ATT 許諾プロンプトが、初回起動時に提示される。

**Why this priority**: 収益源だが、広告が無くてもゲーム機能は完全に動作
するので別個の増分。憲法 IV にも準拠する。

**Independent Test**: テスト広告 ID を使って実機で起動 → 初回起動時に ATT
プロンプトが出る → ゲーム画面下部にバナー広告（テスト広告）が表示されて
いる → 広告領域とプレイ可能領域が重ならないことを目視確認 → ATT で「許可
しない」を選択した場合でもアプリが完全に動作することを確認。

**Acceptance Scenarios**:

1. **Given** 初回起動、**When** メイン画面が表示される前、**Then** ATT 許諾
   プロンプトが提示される。
2. **Given** EU 圏ユーザーの初回起動、**When** ATT プロンプト後、**Then**
   UMP の GDPR 同意フォームが提示される。
3. **Given** 通常のゲーム画面、**When** プレイヤーが盤面でスワイプする、
   **Then** バナー広告は最下部に表示されたままで、スワイプ判定領域とは
   一切重ならない。
4. **Given** プレイヤーが ATT で「許可しない」を選択、**When** 通常通り遊ぶ、
   **Then** ゲームは全機能動作し、広告は非パーソナライズで表示される（また
   は表示されないが、いずれにせよクラッシュしない）。

### Edge Cases

- **満杯近い盤面でのスワイプで何も動かない**: スワイプ後に盤面が変化せず、
  かつ消える行も無かった場合は、新しいピースを配置せず、プレイヤーに別方向
  へのスワイプを促す（無効スワイプ扱い）。それでも次のピースが入るかは
  通常通りゲームオーバー判定を行う。
- **複数行同時消去**: スワイプ後に最大 4 行が同時に揃う可能性がある。スコア
  はテトリス式のボーナス表に従って計算する。1 回のスワイプで 4 行同時消し
  が起きた場合は専用エフェクト（音・ハプティクス・視覚演出）を出す。
- **ピースが入らない（ゲームオーバー）**: 7 種類のピースのうち、現在の盤面
  状態と次のピースの組み合わせ次第では、置ける場所がまったく無くなる。この
  時点で即ゲームオーバーとし、最終スコアを表示する。
- **新規ピースの配置で行が完成する稀ケース**: ピース配置直後に偶然横一行が
  揃った場合、即座にその行を消去しスコア加算する（プレイヤーの操作なしで
  起こる消去にもボーナスを適用する）。
- **アプリのバックグラウンド復帰**: ゲームプレイ中にアプリがバックグラウンド
  に入り、復帰したとき、盤面・スコア・NEXT ピースは中断時の状態が維持される。
- **音・ハプティクスのデフォルト**: 初回起動時、音は ON、ハプティクスは ON
  をデフォルトとする（端末側のサイレントモードはシステム挙動に従う）。
- **複数言語・縦長デバイス vs iPad**: 5 言語のいずれでも、iPhone（縦長）と
  iPad の両方でレイアウトが崩れない。盤面は中央に正方形として配置し、上下に
  HUD（スコア・NEXT）と広告を配置する。
- **テスト用デバッグ端末**: 開発時は AdMob のテスト広告 ID を使い、本番
  リリースまで実広告は出さない。

## Requirements *(mandatory)*

### Functional Requirements

#### 盤面と基本ゲームループ

- **FR-001**: 盤面は **10 行 × 10 列** の正方グリッドで構成される。
- **FR-002**: ゲーム開始時、盤面は完全に空である。
- **FR-003**: ゲーム開始時、システムは即座に最初のピース 1 個を盤面のランダ
  ムな空きマスにランダム回転で配置する。
- **FR-004**: 盤面に置かれた各セルは、配置直後から個別に独立した状態となり、
  以後はピースの形を保たない（2048 と同様にセル単位で挙動する）。

#### ピース

- **FR-005**: 使用するピース種別は **テトリスの 7 種**（I / O / T / S / Z /
  J / L）に限定される。各ピースは 4 セルから成る。
- **FR-006**: ピースの抽選は、I / O / T / S / Z / J / L から **完全一様
  ランダム**で行う（7-bag は採用しない）。
- **FR-007**: 各ピース種別には固定の色を割り当てる（標準テトリス配色：
  I=シアン、O=黄、T=紫、S=緑、Z=赤、J=青、L=オレンジ）。
- **FR-008**: ピースを盤面に配置する際は、4 種の回転状態（0° / 90° / 180° /
  270°）のうち、盤面の現在状態に「収まる」配置候補をすべて列挙し、その候補
  から一様ランダムに 1 つを選ぶ。

#### スワイプとセルの移動

- **FR-009**: プレイヤーは盤面に対して **上 / 下 / 左 / 右** の 4 方向に
  スワイプ操作ができる。
- **FR-010**: スワイプ判定は、指の移動量が一定閾値（例: 30 pt 以上）かつ
  最大方向が明確な 1 方向に偏った場合に成立する。
- **FR-011**: スワイプ成立時、盤面上のすべての埋まっているセルは、その方向に
  「これ以上動けない位置（壁または他のセル）」まで滑る。すべてのセルが同時
  並行に処理されるイメージで、隙間が完全に詰まる。
- **FR-012**: セル同士は **合体しない**（2048 と異なる）。同色 / 同種でも
  ぶつかった時点で停止する。
- **FR-013**: スワイプの結果として盤面が一切変化せず、かつ消える行も無かった
  場合、それは **無効スワイプ**として扱い、ピース配置・スコア加算・NEXT
  更新を行わない。プレイヤーは別方向のスワイプを試せる。

#### 行消去とスコア

- **FR-014**: スワイプ処理（FR-011）の直後、横 1 行（10 セル）がすべて埋ま
  っている行をすべて検出して同時に消去する。
- **FR-015**: 消去対象は **横の行のみ**で、列の消去は行わない。
- **FR-016**: 行消去後、消えた行よりも上にあったセルは **下に詰めず**、その
  ままの位置に留まる（一般的なテトリスの「重力で落下」とは異なる）。
- **FR-017**: 1 回のスワイプで同時に消えた行数 N に応じて、以下のスコアを
  加算する：
  - N=1: +100 点
  - N=2: +300 点
  - N=3: +500 点
  - N=4: +800 点
  - N=0: 加算なし
- **FR-018**: スワイプ＋行消去が完了し、新しいピースを配置できた場合、ピース
  設置ボーナスとして +1 点を加算する。

#### NEXT ピース表示

- **FR-019**: 画面の決まった位置に、次に登場するピース 1 個分の形と色を
  プレビューとして表示する（ゲーム開始時から見える）。
- **FR-020**: HOLD 機能は提供しない。

#### ゲームオーバー判定

- **FR-021**: スワイプ＋行消去のあと、次のピース（NEXT）について、4 種の
  回転と盤面のすべての位置を試して、空き 4 セルにぴったり収まる候補が
  1 つも存在しない場合、ゲームオーバーとする。
- **FR-022**: ゲームオーバー時、最終スコアと（達成した場合は）NEW HIGH
  SCORE 表示を含むゲームオーバー画面を表示し、PLAY AGAIN と MAIN MENU の
  選択肢を提示する。

#### ハイスコア

- **FR-023**: アプリは端末ローカルにエンドレスモードのハイスコアを 1 つだけ
  永続的に保存する。
- **FR-024**: アプリ再起動後もハイスコアは保持され、メイン画面に表示される。
- **FR-025**: 1 回のセッションでハイスコアを更新した場合、ゲームオーバー
  画面で NEW HIGH SCORE を明示的に祝福表示する。

#### 一時停止と復帰

- **FR-026**: ゲーム中に画面上のポーズボタンをタップ、またはアプリがバック
  グラウンドに入った場合、ゲームは一時停止する。タイマーは無いが、アニメー
  ションや効果音が継続しないようにする。
- **FR-027**: バックグラウンドからの復帰時、盤面・スコア・NEXT は中断時と
  同じ状態に戻る。

#### 効果音とハプティクス

- **FR-028**: 以下のイベントで効果音を再生する：スワイプ成功、通常行消去
  （1〜3 行）、4 行同時消し（テトリス）、ゲームオーバー。
- **FR-029**: 以下のイベントでハプティクスフィードバックを再生する：スワイプ
  成功（軽）、行消去（中）、4 行同時消し（強）、ゲームオーバー（強）。
- **FR-030**: 設定画面で「効果音 ON/OFF」と「ハプティクス ON/OFF」をそれぞれ
  独立に切り替えできる。設定は永続化される。

#### 多言語対応

- **FR-031**: アプリは英語 / 日本語 / 簡体字中国語 / 繁体字中国語 / 香港中文
  の 5 言語をサポートする。
- **FR-032**: 端末の言語設定に従って表示言語を自動切替する（アプリ内での
  言語切替 UI は提供しない）。
- **FR-033**: ハードコードされた UI 文字列は許容しない（憲法 III）。

#### 広告とプライバシー

- **FR-034**: ゲーム画面最下部にバナー広告を常時表示する。バナーはスワイプ
  ジェスチャー認識領域と重ならない。
- **FR-035**: インタースティシャル広告およびアプリ起動時のオープン広告は
  **使用しない**。
- **FR-036**: 初回起動時、ATT（App Tracking Transparency）の許諾プロンプト
  を表示する。
- **FR-037**: EU 圏のユーザーには Google UMP の GDPR 同意フォームを提示する。
- **FR-038**: ATT・UMP のいずれの結果でも、ゲーム本編はすべての機能が動作
  する（追跡同意の有無で機能差を設けない）。

#### コードベースの完全置換

- **FR-039**: 既存のゲームモード（Classic View / ProMax View / Reverse
  View）はすべて削除する。新アプリにはエンドレスモードのみ存在する。
- **FR-040**: 既存の効果音・アイコン資産は破棄し、新ゲーム用に新規作成する
  （Sound/ と ICON/ の中身を入れ替える）。
- **FR-041**: アプリのバンドル ID とストア掲載は既存のものを継続使用する
  （新規アプリ申請ではなく、アップデートとしてリリースする）。

### Key Entities

- **Board**: 10×10 のグリッド。各マスは「空」または「埋まっている（特定の色
  を持つセル）」のいずれか。
- **Cell**: 1 つの埋まったマス。色（=元のピース種別）を保持するが、配置後の
  挙動は完全に独立している。
- **Piece**: 4 セルから成るテトリス形状。種別（I / O / T / S / Z / J / L）、
  4 つの回転状態を持つ。盤面に配置された瞬間に Cell へ分解される。
- **GameState**: 現在の Board、現在のスコア、次のピース（NEXT）、ゲーム進行
  状態（プレイ中 / 一時停止 / ゲームオーバー）。
- **Settings**: 効果音 ON/OFF、ハプティクス ON/OFF。永続化される。
- **HighScore**: エンドレスモードでの過去最高スコア。永続化される。
- **AdConsent**: ATT の許諾状態と UMP の GDPR 同意状態。OS / Google UMP に
  よって管理される。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 新ゲームの起動から、初回プレイヤーが PLAY をタップして 1 回目
  のスワイプを行うまでの平均所要時間が **15 秒以内**。
- **SC-002**: スワイプ操作の成立から盤面アニメーション完了までが **200 ms
  以内**で、対応端末で 60 fps を維持する。
- **SC-003**: 1 セッションの平均プレイ時間が **5 分以上 15 分以下**になる
  ように難易度バランスが取れている（社内プレイテストで計測）。
- **SC-004**: ゲームオーバー画面に到達したセッションの **90% 以上**で、
  プレイヤーがすぐ PLAY AGAIN または MAIN MENU を選択できる（クラッシュや
  画面凍結が起きない）。
- **SC-005**: ハイスコアの永続化が確実に機能する：アプリを完全終了して再
  起動したあとに、前回のハイスコアが **100% の試行で**正しく表示される。
- **SC-006**: 5 言語（en / ja / zh-Hans / zh-Hant / zh-HK）すべてで、
  すべてのユーザー向け文字列に翻訳が存在する。プレイテストで翻訳漏れ・
  文字列 ID 表示は **0 件**。
- **SC-007**: ATT を「許可しない」と回答したユーザーにおいても、ゲームの
  全機能（プレイ、ハイスコア、設定変更）が **100% 動作**する。
- **SC-008**: バナー広告がゲーム操作領域を遮蔽する不具合が **発生しない**
  （iPhone SE〜iPhone Pro Max・iPad の主要画面サイズで目視確認）。
- **SC-009**: 4 行同時消し（テトリス）が起きた際、専用効果音・ハプティク
  ス・視覚演出が **100% の試行で**発火する。
- **SC-010**: 既存のコード資産（Classic View / ProMax View / Reverse View）
  は新アプリのバイナリに **0 件含まれない**（完全置換が達成されている）。

## Assumptions

- **対象 OS**: iOS 専用。iPhone および iPad に対応する。最低サポート OS
  バージョンは既存 Xcode プロジェクトの設定を継承し、本仕様の範囲では
  変更しない。
- **アプリの ID と配信**: 既存アプリのアップデート（バンドル ID / App Store
  Connect 上の同一プロダクトを継続使用）として配信する。新規プロダクトとして
  ストアに別途申請しない。
- **ピース色は標準テトリス配色**（I=シアン、O=黄、T=紫、S=緑、Z=赤、J=青、
  L=オレンジ）。色覚多様性への配慮として、各色には十分なコントラストを
  確保する。色覚特性専用モードは本仕様の範囲外（将来の増分）。
- **ハイスコア保存先**: 端末ローカルの永続ストレージ。クラウド同期 /
  Game Center 連携は本仕様の範囲外。
- **ピース抽選アルゴリズム**: 完全一様ランダム（同じピースが連続することも
  許容）。7-bag・履歴調整は採用しない。
- **無効スワイプ後の挙動**: 盤面が動かず行も消えない場合、新ピースを置かず
  プレイヤーに別方向のスワイプをやり直させる（操作の取り消しではない）。
- **ハプティクスは iOS が提供する標準のハプティクスフィードバック機構を
  使う**（具体的なフレームワーク選定は plan で決める）。これに対応しない
  端末ではハプティクスを無視する。
- **既存の Classic / ProMax / Reverse のセーブデータ**: 引き継ぎは行わない。
  既存ハイスコアは初期値 0 として扱う（ユーザーへの説明は別途リリースノート
  で行う）。
- **広告は AdMob のテスト ID で開発を進め、本番リリース時に本物の広告
  ユニット ID に差し替える**。本仕様内では具体的なユニット ID は規定しない。
- **「ピース設置ボーナス +1」**: 1 ピースが盤面に置かれるたびに無条件で
  +1 点。ゲーム開始時に最初のピースが配置される瞬間にも適用する。

## Out of Scope

以下は本仕様の範囲外（将来の増分として検討可能）：

- ハイスコア以外のリーダーボード（Game Center、独自サーバー等）。
- 複数のゲームモード（タイムアタック、デイリーパズル、レベル制等）。
- HOLD 機能、ピースのプレイヤー回転操作、上端からの落下式テトリス操作。
- アプリ内通貨 / 課金 / 広告除去アイテム。
- 色覚特性専用カラーモード、ダーク / ライトテーマ手動切替。
- カスタム盤面サイズ、難易度設定。
- アプリ内での言語切替 UI（端末設定に追従するため）。
- iCloud / クロスデバイス同期。
- Android / Web / macOS 版。
